# Смена

Адаптивный одностраничный сайт на HTML, CSS и JavaScript. После правок заказчика — шесть блоков: первый экран со шапкой, услуги, предложенный порядок работы, «Почему мы», вопросы и подвал.

## Просмотр

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны. Все изображения и шрифт находятся в проекте; внешние сервисы, аналитика, формы и виджеты не подключены.

Для просмотра через локальный сервер из папки проекта:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Затем откройте http://127.0.0.1:4173. Для остановки нажмите Ctrl+C в терминале.

## Файлы

- `index.html` — содержимое, метаданные и семантическая разметка.
- `css/style.css` — палитра, типографика, сетки, адаптивность и состояния элементов.
- `js/main.js` — мобильная навигация, всплывающие описания услуг, одиночное раскрытие вопросов и появления при прокрутке.
- `assets/images/` — три сгенерированных изображения: JPG и адаптивные WebP размером 640 и 1100 px по ширине.
- `assets/fonts/` — Golos Text с кириллицей, лицензия SIL Open Font License 1.1 в `OFL.txt`.
- `IMAGE-PROMPTS.md` — промпты изображений, созданных встроенным инструментом imagegen.
- `QA.md` — результаты проверки и её ограничения.

## Поведение

Все телефонные ссылки используют `tel:+79261704060`. Стрелки у двух услуг открывают описания в модальных окнах: по три предложения и четыре примера сотрудников для каждого направления. Окна плавно появляются и закрываются крестиком, по Escape или нажатием на фон. Фокус остаётся внутри окна и после закрытия возвращается на стрелку. Без JavaScript подробности доступны через раскрываемые описания в карточках.

Меню на мобильных экранах раскрывается кнопкой, закрывается после выбора ссылки и по Escape. На широком экране ссылки видны постоянно. Без JavaScript навигация остаётся видимой, а вопросы работают через стандартные `details` и `summary`. Вместо вопроса «Как связаться?» добавлен «Что нужно для обсуждения задачи?».

Основное содержимое всегда видно, даже если скрипт не загрузился. `prefers-reduced-motion` отключает плавную прокрутку, переходы и появления. Фотографии услуг загружаются отложенно. Изображения имеют текстовые описания и не выдаются за реальные фотографии объектов или сотрудников заказчика.

## Контент

Текущая версия опубликована по запросу заказчика. Блок «Почему мы» добавлен после «Как работаем» по правкам заказчика от 25 ноября 2026 года; четыре преимущества взяты из предоставленного референса. По тому же запросу добавлены описания услуг и примеры сотрудников: складские и производственные должности. Цены, конкретные сроки, география и количественные достижения не добавлялись. Дополнительные фотографии, контакты и интеграции можно согласовать отдельно.

Для обычного статического хостинга загрузите `index.html` и папки `css`, `js`, `assets`, сохранив их относительное расположение. Документацию публиковать не требуется. Серверная часть, API-ключи и переменные окружения не нужны.


## GitHub и Vercel

- Сайт: https://smena-ochre.vercel.app
- Репозиторий: https://github.com/abdulguna216-pixel/smena
- Проект Vercel: https://vercel.com/abdulguna216-4917/smena
- Production-ветка: `main`. Новые коммиты автоматически запускают сборку и обновляют сайт.

Vercel запускает `node scripts/build.mjs`; команда копирует `index.html`, `css`, `js` и `assets` в `dist/`. Установка зависимостей не требуется. Настройки находятся в `vercel.json`. Документация и локальный ZIP не попадают в опубликованные файлы.

Локальный Git связан с репозиторием через `origin`. Локальная привязка Vercel находится в игнорируемой папке `.vercel/`.
